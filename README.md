# ExpenseTracker

This is a simple and interactive **Expense Tracker** web application built with **HTML, CSS, and JavaScript**.  
This project allows users to add, delete, and track their income and expenses in real time.

---

## 🌐 Live Demo

👉 [View Live Demo](https://expensetracker-malakintech.netlify.app/)

---

## 🚀 Features

- ➕ Add income and expense transactions  
- ❌ Delete transactions  
- 📊 Automatically calculate total balance  
- 📈 Display total income and total expenses  
- 💾 Data saved in Local Storage (persists after page refresh)  
- 📱 Responsive design (mobile-friendly)

---

## 🛠️ Technologies Used

- **HTML5** – Application structure  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – Application logic

## ⚙️ How It Works

1. The user enters a transaction description and an amount.
2. If the amount is positive → it is treated as **income**.
3. If the amount is negative → it is treated as an **expense**.
4. The application automatically updates:
   - Total Balance
   - Total Income
   - Total Expenses
5. All transactions are stored in **Local Storage**.
